遊戲規則與幾何判定說明

1. 開局設定：在 0 ≤ X ≤ L、0 ≤ Y ≤ L 的正整數直角坐標系統上隨機生成 n 個不重複的坐標點，共有 k 名玩家輪流進行回合。

2. 連線規則：每位玩家在自己的回合可選擇場上任意兩點連成一條新線段（可直接點擊棋盤上的兩點，或在右側選單選擇兩點）。

3. 三角形得分與獎勵回合：當玩家新連上的線段與場上已有的其他兩條線段組成三角形（三頂點皆為已連線的場上點）時：

  • 每組成一個新三角形，該玩家獲得 +1 分（若一線同時在兩側構成兩個三角形則得 2 分）。
  • 得分的玩家可立即再進行一個額外回合！

4. 線段相交與封鎖區域限制：已組成三角形的內部區域即被永久封鎖（塗上得分玩家的代表色）。之後任何玩家生成的線段：

  • 不可穿過（相交）場上任何已存在的線段（僅允許在坐標端點處相連以構成折線或三角形）。
  • 不可穿過任何封鎖三角形的內部區域或切割封鎖三角形的邊。
  • 也不允許新生成的線段直接跨過場上共線的第三個點。

5. 勝負判定：當輪到某位玩家時，場上已無任何合法的兩點可供連線，遊戲立即結束，由總得分最高的玩家獲勝！
